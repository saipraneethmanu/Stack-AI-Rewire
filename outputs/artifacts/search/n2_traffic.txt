The **Municipality of Bologna (Comune di Bologna)** publishes official open datasets containing hourly road traffic volumes measured across the city's inductive loop sensor network.

---

### Dataset Details

* **City:** Bologna, Italy
* **Publisher:** Comune di Bologna
* **License:** **Creative Commons Attribution 4.0 International (CC BY 4.0)**
* **Temporal Granularity:** Hourly vehicle counts across a 24-hour day
* **Spatial Granularity:** Sensor location / loop ID (`ID_univoco_stazione_spira`, street name, latitude, longitude, and GIS geopoint)
* **Available Formats:** CSV, JSON, GeoJSON, Parquet, and Opendatasoft REST API

### Data Schema Overview
Each row in the dataset corresponds to a counter station for a specific calendar date and contains:
* **Sensor/Location Metadata:** `ID_univoco_stazione_spira`, `codice`, `nome_via` (street name), `direzione` (travel direction), `latitudine`, `longitudine`, `geopoint`.
* **Time Information:** `data` (date), `giorno` / `num_giorno_settimana` (day of week).
* **Hourly Counts:** Columns representing the detected traffic volumes by hour of the day.
* **Accuracy:** A companion accuracy metric indicating sensor operating health.
